# Visual reference brief

Original stylized Franco-Alpine municipal environment. Warm limestone/concrete, navy institutional paint, faded amber markings, grey camera housings, fir trees, and restrained low-poly vehicles. Keep radar silhouette and lane sight lines readable at driver height.

Prepare matching front/side/back reference sheets for one battered patrol compact and one fixed camera before commissioning or generating final assets. Start with primitive geometry. No third-party or generated art is currently included.
